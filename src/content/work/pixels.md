I wanted to dither an image and every tool I found wanted me to upload it somewhere first. For a photo I had not published yet, that felt like the wrong trade. So Pixels does all of it in the browser. Nothing leaves your machine.

## Six algorithms

Floyd-Steinberg, Atkinson, Bayer, Stucki, Burkes and Sierra. Each one scatters its error differently, so the same photo takes on a different character with each.

## Controls

Threshold, strength and dot size to push around, and a two-colour palette you set yourself. Noise, vignette, glitch and chromatic aberration sit on top if you want to ruin it properly.

Drop, paste or browse an image in. Export at up to 4x. No account, no upload, no waiting.
